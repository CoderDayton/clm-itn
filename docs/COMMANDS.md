## Install

```bash
cargo install clm-itn
```

From a checkout, `cargo build --release` writes `target/release/clm-itn`.

## clm-itn

Text arguments, one output line each:

```bash
clm-itn "whats four times four" "at five thirty pm"
```

Files and pipes:

```bash
clm-itn -f notes.txt -f more.txt > written.txt
clm-itn < spoken.txt > written.txt
echo "at five thirty pm" | clm-itn
```

Switch settings off with `--no-<setting>`, turn on `--single-digits`, or use the combinable short forms that flip a setting from its default, and write JSON with `--json`:

```bash
clm-itn --no-percent --single-digits "like eight years at fifty percent"
clm-itn -dp "like eight years at fifty percent"
clm-itn --json "at five thirty pm"
```

`clm-itn --help` lists every option and setting.

## Build and test

```bash
cargo build --release
cargo test --release
cargo test --doc
cargo doc --no-deps --open
```

The same tasks run through `cargo script`: `build`, `release`, `test`, `doc`.

## Lint

```bash
cargo fmt
cargo clippy --all-targets --all-features -- -D warnings
cargo clippy --lib --no-default-features -- -D warnings
```

`cargo script lint` formats and lints; `cargo script lint-ci` checks without changing files, with and without `std`.

## Benchmarks

Pin the benchmark to one core for sign-off numbers.

```bash
taskset -c 2 cargo bench --bench clm-bench                  # p99 gate
taskset -c 2 cargo bench --bench clm-bench -- --tiers       # plus per-stage split
taskset -c 2 cargo bench --bench clm-bench -- --corpus tests/data
taskset -c 2 cargo bench --bench clm-bench -- --corpus tests/data/paragraph.jsonl --passes 10000 --sentences
```

`cargo script bench`, `bench-tiers`, `bench-corpus` and `bench-paragraph` run the same commands. Method and results are in [PERFORMANCE.md](PERFORMANCE.md).

## Rebuild the tables

The tables are generated by `build.rs` from `src/builder/`; `cargo build` rebuilds them. `clm-learn` fits learned ranks from a pairs folder:

```bash
cargo run --release --features internals --bin clm-learn -- <pairs dir> <learned.txt out>
```

See [TRAINING.md](TRAINING.md) for the data and the options.
